# Forum saumurois

Projet de plateforme citoyenne de signalements pour Saumur et les communes de Saumur Val de Loire.

## Objectif de migration

- Hébergement statique : Cloudflare Pages
- API : Cloudflare Workers
- Base de données : Cloudflare D1
- Accès public sans compte Hatchable

## Données

Les adresses saisies par les utilisateurs restent visibles publiquement, conformément au choix du projet. Les signalements sont des déclarations citoyennes et ne constituent pas des faits établis.

## État

Le dépôt sert actuellement de base de migration. Le code de l'application et l'adaptation de l'API doivent encore être transférés et testés avant tout déploiement public.
